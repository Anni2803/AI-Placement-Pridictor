# AI Placement Predictor & Skill Improvement System

## Project Overview

The AI Placement Predictor & Skill Improvement System is a Python-based project that predicts whether a student is likely to be placed based on their academic and technical skills.

The project uses Machine Learning (Decision Tree Classifier) to analyze student data and provide placement predictions. It also suggests which skills need improvement if the prediction is "Not Placed".

## Machine Learning Model

Algorithm Used:
- Decision Tree Classifier

Input Features:
- CGPA
- Python Skill
- SQL Skill
- DSA Skill
- Communication
- Aptitude
- Projects
- Certifications
- Resume Score

Output:
- Placed
- Not Placed
